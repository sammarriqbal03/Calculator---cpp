# Calculator (C++)

## 📌 Description

This is a console-based calculator built in C++. It supports basic arithmetic operations along with advanced features like factorial, power, and memory storage.

## 🎯 Features

* Addition, Subtraction, Multiplication, Division
* Power calculation (x^y)
* Factorial calculation (!)
* Memory functions (store, recall, clear)
* Reuse previous result
* Restart or continue calculations

## 🛠️ Technologies Used

* C++
* Standard Libraries (iostream, cmath, cstring)

## ▶️ How to Run

1. Open terminal or command prompt
2. Compile the code:
   g++ calculator.cpp -o calculator
3. Run the program:
   calculator

## 📷 Sample Output

Operators available:
